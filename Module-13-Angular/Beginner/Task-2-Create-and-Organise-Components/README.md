# Module 13 - Task 2: Create and Organise Components

## Objective
Generate reusable Angular components and organize them into a simple Student Course Portal.

## Components Created

- Header
- Home
- Course List
- Student Profile

## Steps Performed

1. Generated four components using Angular CLI.
2. Created a navigation header.
3. Added welcome content to the Home page.
4. Updated the root component to display the header and home page.
5. Verified the application using `ng serve`.

## Output

The application displays:

- Student Course Portal
- Home | Courses | Profile
- Welcome message
- Portal statistics
